## What happened this session

1. **Accent reframe (B9).** The accent's own brightness tracks ReBirth on an
   isolated fixture; `ACC_SWEEP` is not the deficit. The tour attribution was a
   confound. The real gap was the env-mod corner at high env mod. Section 26.
2. **Env-mod corner refit REJECTED (B9 + net), section 27-28.** A global
   `EM_OCT`/`EM_CURVE` lift closes the corner but regresses the env-mod net
   fixtures; the deficit is a reso x envmod interaction. Added `EM_RESO` (probe,
   default 0.0) to test a reso-gated term. It closes the corner but the ear check
   showed it does not deliver the audible win, so it is BANKED as a probe.
3. **The round chirp CHARACTERIZED (B10 + `chirp_peak.py`), section 29.** At reso
   90 to 110 ReBirth's resonant peak rides the filter sweep on each note; ours did
   not, because the buffered 4-pole ladder is capped at k=4.0 self-oscillation.
   Matching centroid (the corner) did nothing because the chirp is resonance
   STRENGTH, not corner position.
4. **SHIPPED: the held chirp via `FB_SEP`, section 30.** The old resonance path
   summed input and feedback then clipped them together, ducking the resonance.
   `FB_SEP` clips the input alone and subtracts the feedback after, so it rings
   freely. **`FB_SEP` default 0 -> 1 on Luke's ear sign-off** ("remarkably close
   to ReBirth", voice intact at reso 88, no whistle). Resonance params UNCHANGED
   (tuning showed shipped is the balance; cranking over-resonates statics). Rides
   the HELD chirp; net +0.74 which is largely the time-domain ride the band-shape
   net cannot credit.
5. **The RETRIGGERED per-beat curve is the last gap**, and it needs the coupled
   ladder. FB_SEP does not ride it (TPT's zero-delay stages settle too fast to
   ring up on a fast pluck). Luke's ear: "a curve on every beat... ours sounds
   more of an accent" (measured per-beat centroid rise 165 Hz ours vs 376 RB).

## The diode branch: viability PROVEN (exp/diode-ladder-chirp)

Off the FB_SEP ship. Two results establish it as the real path for the
retriggered curve, where the forward-Euler `rb` core was a dead end:

- **It RIDES the retriggered curve.** The backward-Euler `diode` core, flat until
  its feedback gain was raised (`D_K` ~10, `D_G` 0.5, `D_VT` 0.3), rides
  b10_r100_saw 215->420->799->221 tracking the corner sweep, where the buffered
  core stays flat.
- **Its AUDIBLE band-shape matches ReBirth.** Reso-0 rolloff (the make-or-break
  the `rb` core failed at 6 to 9 dB dark): energy-weighted band error 1.10 dB,
  TPT-class. A +7 to +10 dB HF excess above 4.5 kHz inflates the FLAT net (3.33)
  but sits in bands holding 0.05% of the energy, so it is inaudible.

Open on the branch (`PLAN_DIODE_CHIRP.md`): (a) cut the inaudible HF excess so the
flat net agrees with the ear (not simple output HF; `D_HF` one-pole LP did not
flatten it, likely post-filter-path or discretization); (b) fine-tune the ride to
RB's peak; (c) full cutoff/reso fit vs the sysid references; (d) net + song + B10
A/B. If it rides AND reaches net parity, it is a candidate to replace the buffered
core, a Luke sign-off (a core swap).
