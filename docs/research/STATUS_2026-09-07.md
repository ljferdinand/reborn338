## Measurement gotchas learned this round (PCF)

- ReBirth exports are NOT sample-deterministic: per-frame time-aligned level
  analysis is invalid. Use steady sources + amplitude envelopes, or medians.
- The 303 drone can't resolve high/moving cutoffs; the broadband drum probe is
  unreliable for the STATIC transfer (transient noise) though fine for the decay
  TRAJECTORY. The 2-pole fit absorbs shape as a phantom corner. For the static
  filter use the drone harmonic-by-harmonic, passband-normalised.
- A cutoff peak is only measurable while it is IN-BAND (< ~8 kHz); over-opened
  cutoffs sit above the source and can't be read directly.
